# Secure Password Generator

A lightweight command-line tool written in Python that generates cryptographically strong, random passwords using standard library modules.

## Features

- **Cryptographically Secure:** Uses Python's `secrets` module instead of pseudo-random generators (`random`).
- **Comprehensive Character Pool:** Combines uppercase/lowercase letters, numbers, and special symbols via the `string` module.
- **Zero Dependencies:** Runs entirely on Python standard library modules without requiring external packages.
